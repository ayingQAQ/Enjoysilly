# 兼容性与提示词诊断（v0.6 优先批次）

更新：2026-10-29。版本号仍为 0.3.0；本批次不是完整 v0.6 发布验收。

## 分级含义

资产详情中的报告按能力分级，而不是给整张卡贴“完全兼容”标签。报告只读，不改写导出数据；证据路径来自当前资产。脚本依赖检测是启发式，不能证明不存在其他依赖。

| 级别 | 当前范围 |
| --- | --- |
| 完整支持 | 已支持格式的字段往返、基础世界书扫描、预设排序与启用 |
| 部分支持 | 角色设定按 marker 组装、受限 HTML/CSS、已有正则替换链路、部分采样参数 |
| 仅保留 | 未知扩展、未实现 marker、高级提示词注入、未执行的世界书字段 |
| 不执行 | 任意卡片 JavaScript、TavernHelper、MVU 等运行时 |

“修仙世界”这类依赖脚本生成状态栏的卡片，可能只能显示模板或静态内容。保留原始脚本和扩展供往返，不代表执行它们。

## 发送前预览

在对话输入非空后点击“预览提示词”。抽屉显示宏展开和提示词正则处理后的实际消息顺序、来源、角色设定、历史与世界书文本，以及启发式 token 估算。不会读取连接密钥到显示模型，不会请求模型或写入聊天存档；输入草稿仍按既有机制保存。

“发送此预览”使用已查看的组装快照，随机/时间宏与概率不重新采样。输入、历史或资产变化会使旧快照失效；关闭不会清空输入。当前只覆盖下一条普通消息，重生成、继续和群聊仍走原有流程，没有独立预览入口。估算不是模型 tokenizer，也不执行上下文截断或输出预算分配。

## 世界书说明与实际边界

- 每条源记录独立编号，重复 uid 不合并；显示停用、空内容、关键词、常驻、次要关键词、概率、递归轮次和预算淘汰结果。
- 当前聊天仍采用既有默认开关：selective、概率、递归、tokenBudget 未启用。底层扫描器的可选功能有测试，不能据此宣称聊天已经启用它们。报告明确显示未启用原因。
- sticky、cooldown、delay、分组竞争、向量检索、整词匹配等字段仅保留；高级插入位置可能回退到角色前，详情会提示。
- “扫描选中”不是“已发送”：角色前/后需要预设的 worldInfoBefore/worldInfoAfter，深度条目需要 chatHistory；最终以上方实际请求正文为准。
- 角色内嵌世界书优先于默认独立世界书，当前不合并两个来源；历史仍按现有 marker 合并为文本。
- 未实现的动态 marker 不生成正文；injection_* / forbid_overrides 不参与执行；角色 system_prompt 不自动覆盖预设 main。

## 验证与后续

自动测试覆盖真实修仙世界和 DarkSide 样本报告、不可变往返、重复 uid、递归与预算边界、最终正则、当前 swipe、快照复用和过期异步结果。浏览器命令 `npm run test:preview` 使用本地模拟请求，检查 360 / 768 / 1440 宽度、无存档写入、密钥不显示、请求正文与预览一致、Escape 焦点归还。

后续仍需：扩充具名损坏文件与多 swipe 黄金样本、真实 SillyTavern 导入抽检、Firefox 回归，以及第四阶段上下文预算与 timed effects。未将这些人工或后续验收算作本批次完成。

独立审查无阻断项；已知小项：便携字段 group_override / group_weight / use_group_scoring / automation_id 暂缺专门的逐字段执行提示，通用扩展保留说明仍在。后续补别名归一化与测试。预览冻结准备时的时间值；跨标签页资产变更仍需按既有方式刷新，不新增实时同步。大输入的每次渲染序列化成本尚未专项测量。
